# 🌿 Projeto Agrinho: Criando Seu Próprio Portal do Futuro da Agronomia!

Olá, futuro(a) programador(a)! 👋 Bem-vindo(a) ao guia passo a passo para construir e rodar o site **Agrinho**. Este site foi feito para espalhar ideias incríveis sobre como a tecnologia e o carinho com a Terra podem transformar o nosso futuro.

Prepare-se para se tornar um(a) mestre dos códigos! Siga cada passo abaixo e veja a mágica acontecer na tela do seu computador. 🚀

---

## 🎒 Passo 1: Abrindo a sua Caixa de Ferramentas (Acessar o OneCompiler)

Para escrever e rodar nossos códigos, vamos usar o **OneCompiler** — uma ferramenta incrível que funciona diretamente no navegador, sem precisar instalar **nada** no computador!

1. **Abra o navegador** de internet do seu computador (Google Chrome, Edge, Firefox…).
2. **Acesse o site:** [onecompiler.com/html](https://onecompiler.com/html)
3. A página vai abrir com um editor já prontinho para usar, com três abas: **HTML**, **CSS** e **JS**. Essas são exatamente as três linguagens do nosso projeto!

> 💡 **Dica:** Não precisa criar conta para testar! Mas se quiser salvar e compartilhar seu projeto depois, crie uma conta gratuita clicando em **Sign Up** no canto superior direito.

---

## 🎨 Passo 2: Conhecendo as Abas do Editor

O OneCompiler já vem com tudo separado e organizado, como um caderno com divisórias coloridas! Veja o que cada aba representa:

- **Aba HTML →** É o esqueleto do site. Aqui ficam os textos, títulos e imagens.
- **Aba CSS →** É o estilista do site! Aqui ficam as cores, tamanhos de letra e o visual do Modo Claro e Escuro.
- **Aba JS →** É o cérebro! Aqui fica o JavaScript que faz os botões funcionarem, a leitura em voz alta e muito mais.

Clique em cada aba para alternar entre elas. Simples assim! 😄

---

## 📝 Passo 3: Adicionando os Arquivos de Código

Agora vamos colocar o código do projeto dentro de cada aba. Siga a ordem abaixo:

### 1️⃣ O Esqueleto: aba `HTML`

O HTML cuida de todos os textos, títulos e imagens do site. É a estrutura dele!

1. Clique na aba **HTML** no editor.
2. Apague o conteúdo que já está lá (selecione tudo com `Ctrl + A` e delete).
3. Cole todo o conteúdo do arquivo `index.html` do projeto aqui dentro.

### 2️⃣ A Roupa e as Cores: aba `CSS`

O CSS é o estilista do site! Ele decide as cores do Modo Claro, do Modo Escuro, o tamanho das letras e deixa tudo alinhado e bonito.

1. Clique na aba **CSS** no editor.
2. Apague o conteúdo existente.
3. Cole todo o conteúdo do arquivo `styles.css` do projeto aqui dentro.

### 3️⃣ O Cérebro: aba `JS`

O JavaScript dá vida e interatividade ao site! Ele faz o botão do Modo Escuro funcionar, aumenta e diminui a letra e até lê o texto em voz alta para quem precisa!

1. Clique na aba **JS** no editor.
2. Apague o conteúdo existente.
3. Cole todo o conteúdo do arquivo `java.js` do projeto aqui dentro.

---

## 🚀 Passo 4: A Hora do Show (Rodar o Site!)

Agora que os três códigos estão nas abas certas, vamos ver o site funcionar de verdade!

1. Olhe para o canto superior do editor e procure o botão verde escrito **▶ Run**.
2. **Clique em Run!** ✨
3. Um painel de **Output** (resultado) vai aparecer à direita da tela mostrando o seu site lindo e funcionando!

> 💡 **Dica de Ouro:** Toda vez que você mudar alguma coisa no código e clicar em **Run** de novo, o site atualiza na hora. É como ter um Live Server direto no navegador!

---

## 💾 Passo 5: Salvando e Compartilhando o Projeto (Opcional)

Quer guardar seu trabalho ou mostrar para alguém? É fácil!

1. Clique no botão **Save** (ou `Ctrl + S`) no OneCompiler.
2. Se ainda não tiver conta, o site vai pedir para você criar uma — é gratuita!
3. Após salvar, você receberá um **link único** do tipo `onecompiler.com/html/xxxxxxx`.
4. É só copiar esse link e enviar para quem quiser mostrar o projeto. A pessoa consegue abrir direto no navegador, sem instalar nada!

---

## 🎮 Como Usar a Barra de Acessibilidade Flutuante?

No cantinho inferior direito da tela do seu site, um menu redondo muito legal vai aparecer com vários botões mágicos:

- **A+ e A-:** Aumentam ou diminuem o tamanho das letras para quem tem dificuldade de ler coisas miúdas.
- **A:** Volta a letra para o tamanho original.
- **🌙 (Lua):** Transforma o site para o **Modo Escuro** instantaneamente (ótimo para ler à noite sem cansar os olhos!). Clicando de novo ele volta para o Modo Claro.
- **🔊 (Som):** O computador começa a ler todos os artigos do site em voz alta para você!
- **■ (Quadrado):** Para a leitura de voz imediatamente.
